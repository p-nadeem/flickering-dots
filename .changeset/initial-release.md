First release: dot-matrix loading, thinking and typing indicators with 85 animated presets, a React component (`flickering-dots/react`), a `<flickering-dots>` custom element (`flickering-dots/element`, `flickering-dots/element/define`) and a framework-agnostic core (`flickering-dots`). Presets load on demand, about 14 kB gzip up front.
